# California Hospital DentalGroup website

Static, responsive website files. Open `index.html` in a browser for a local preview or publish the folder on a static web host.

## Before launch

- Replace `https://example.com/` in the canonical link, Open Graph URL, `robots.txt`, and `sitemap.xml` with the clinic's verified domain.
- Connect the appointment form to the clinic's approved booking system or form endpoint. Until then, it validates fields locally and clearly tells visitors to call; it does not transmit or store their information.
- Confirm which services and technologies are offered at this location. The current service labels are general categories, explicitly identified as unconfirmed.
- Replace the editorial photography with clinic-approved photography if available. The current images load from Unsplash.
- Supply the clinic's privacy policy and terms before publishing those pages. The footer currently opens informational placeholders.

No build step or package installation is required.
